# Framewise for iPhone

Framewise is a camera composition guide for SideStore and LiveContainer.

## Add the SideStore source

Copy this source URL into SideStore:

`https://github.com/hesm4tt/framewise-ipa/releases/latest/download/framewise.json`

The source JSON is attached to every release and the `latest` URL follows the newest release. This avoids relying on GitHub's short-lived raw-branch cache.

Direct IPA URL for the newest release:

`https://github.com/hesm4tt/framewise-ipa/releases/latest/download/Framewise.ipa`

The app identifier is `com.framewise.camera`. The source identifier is `com.framewise.source`; keep both identifiers stable when publishing updates.
