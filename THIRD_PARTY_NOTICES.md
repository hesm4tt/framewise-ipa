## YOLOv3 Tiny Core ML model

`Framewise/YOLOv3TinyInt8LUT.mlmodel` is Apple’s 8.9 MB quantized Core ML distribution of YOLOv3 Tiny. It uses the COCO 80-class labels and was authored by Joseph Redmon and Ali Farhadi. The model metadata points to the Darknet YOLO License, which places Darknet in the public domain and permits reuse.
